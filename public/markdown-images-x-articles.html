Markdown images in X Articles, including Obsidian notes

A Markdown file only stores image paths such as assets/chart.png. When you paste it into X, those paths mean nothing, and uploading each image by hand in the right spot is slow. Article Studio matches the paths to your files and places every image where it appears in the text.

Steps

  1. Import or paste your Markdown in Article Studio.
  2. Open Images & diagrams and choose the folder that holds your images, or a parent folder. Browsers cannot read local paths without your permission, so this step is needed once per article. Only images the article references are attached.
  3. Fix anything the preview marks as missing with the image's Replace control. You can use a local file or a public image URL.
  4. With the Chrome companion, choose Create X draft. Images are uploaded to your signed-in X account and placed in order. Without the companion, copy the body and add the images in X where the image markers show.

Obsidian notes

Obsidian image paths are usually relative to the vault or to the note. Select the vault folder, or the attachments folder you use, and Article Studio matches the paths inside it.

Article Studio reads standard Markdown image links like ![Chart](attachments/chart.png). Obsidian's wikilink embeds, such as ![[chart.png]], are not recognized as images. In Obsidian, turn off Settings → Files and links → Use [[Wikilinks]] so new embeds use Markdown links, and update existing embeds before importing.

Supported images

  • PNG, JPEG and WebP, up to 5 MiB each.
  • Up to 40 images and 20 MiB of image data per draft. Mermaid diagrams and PNG tables count toward the total.
  • Public web images work when the host allows browser downloads (CORS). Images behind a login, private hosts or redirects need a local replacement.
  • If the same image is used more than once, it is uploaded once and every placement is kept.

Limits

  • Images must sit in their own paragraph or in normal text. Images inside lists, headings, quotes, links or tables are blocked. Move them out first.
  • GIF, SVG and video are not supported yet. Add them in X after creating the draft.
  • ALT text stays in your Markdown source and is not set as the image description in X. For a cover image, add cover: path to the frontmatter or choose one under Images; companion 0.1.2 or later sets it on the draft.
