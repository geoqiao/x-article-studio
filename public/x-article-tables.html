How to add a table to an X Article

X stores article tables as Markdown rather than as a separate table element. If your article is already written in Markdown, you do not need to rebuild the table in X's editor: write it as a pipe table and let a converter place it for you.

Article Studio gives you two options for every table: keep it native, stored as a Markdown table inside the X draft, or turn it into a PNG image that you can paste or upload anywhere.

Steps

  1. Write the table as a Markdown pipe table in Article Studio, or import a .md file that already contains one.
  2. Above the preview, set Tables to Native or PNG images.
  3. With the Chrome companion, choose Create X draft. The table goes into the draft in the format you picked.
  4. Without the companion, choose PNG images, copy the body, and add the table images from Images & diagrams → Download all (.zip) where the image markers show.
  5. Open the draft in X and check how the table looks before publishing.

Native table or PNG image?

NativePNG image
How it is storedA Markdown table inside the X draftAn uploaded image
Text and linksStay text; links keep workingFlattened into pixels; links stop working
Inline formattingKept in the table sourceShown as plain text
Copy and paste without the companionMay not paste as a tableWorks as an image
AppearanceDecided by XFixed layout you can preview

Use native tables when readers need to select text or follow links. Use PNG when you paste by hand or want a layout that looks the same everywhere.

Why native tables work

X's documented article format has no separate table block. Its draft schema says tables are stored as Markdown blocks containing a pipe table. Article Studio writes tables in that form. How X renders them in the editor, on the web and in the apps is decided by X, so preview the draft before you publish.

Limits

  • Native tables and code blocks together can hold up to 10,000 characters per article in this app. Switch tables to PNG for longer ones.
  • PNG tables do not reproduce column alignment, and each counts toward the 40-image limit per draft.
  • Images inside table cells are not supported. Move them into their own paragraph.
