How it works

How to convert Markdown to an X Article

Prepare local images, tables and Mermaid diagrams right in your browser. Paste or import, review the live preview, then copy formatted text or create an X draft.

  1. 01

    Paste or import Markdown

    Use a .md file from Obsidian, VS Code or any other editor. The first H1 or frontmatter title becomes the article title, and you can edit it inline at the top of the preview.

  2. 02

    Attach local images once

    Browsers cannot read local paths inside a Markdown file on their own, so choose the image folder in Images & diagrams. Only images referenced by the article are attached.

  3. 03

    Review the live preview

    Mermaid code blocks render as crisp 2× PNG images. Tables stay native or convert to PNG. Anything that would lose content is flagged with a direct line link to your source.

  4. 04

    Copy or create an X draft

    Copy the title and formatted body into X, or use the free Chrome companion to create an unpublished X Article draft with images in place.

What converts

  • Formatted text

    H2 and H3 headings, bold, italic, strikethrough, links, single-level lists, quotes, dividers and code blocks.

    Full format support →

  • Tables

    Kept as native Markdown tables in the companion draft, or rendered as clean PNG images when pasting manually.

    Adding tables to X Articles →

  • Mermaid diagrams

    Flowcharts, sequence diagrams and other Mermaid code blocks automatically render as 2× resolution PNG images.

    Mermaid diagrams in X Articles →

  • Local images

    Local or public PNG, JPEG and WebP files, matched from your folder and placed where they appear in your Markdown.

    Markdown images in X Articles →

Not converted yet: footnotes, raw HTML, GIF, SVG, video and image ALT text. These are flagged in the preview instead of dropped silently. See the full format guide for details.

Frequently asked questions

Is md2xarticle free?

Yes. The editor, copying, ZIP export and the Chrome companion are free to use.

Do I need the Chrome extension?

No. You can copy the title and formatted body without it. The desktop Chrome companion is only needed to upload images and create the draft automatically.

Where is my article stored?

In this browser. Markdown and images are prepared locally. They are sent to X only when you confirm draft creation in the companion, or straight from Create X draft if you turned on that option in the companion. See the privacy policy.

Does it publish to X for me?

No. It creates an unpublished draft in your signed-in X account, and you review and publish it in X. Your account needs access to X Articles, which X controls. X can change its editor, so check each draft before publishing.
