## Description

Convert Markdown into X (Twitter) Article drafts—with local and Obsidian images, native tables, native code blocks, Mermaid diagrams, and cover images placed automatically.

md2xarticle connects the free local-first editor at md2xarticle.com (and the open-source md2xarticle agent skill for Claude Code / Codex) to your signed-in X Articles session. Prepare and preview your article in the browser, review the handoff in the extension, then confirm draft creation. The companion opens X Articles automatically and creates an unpublished draft for you to review and publish in X.

What it handles:
- Import or paste Markdown and preview how it maps to X Articles before uploading.
- Match local image folders and Obsidian ![[image]] embeds once; uploads PNG, JPEG, WebP, and SVG (rendered to PNG) in document order.
- Keep GFM tables as native X Markdown tables—or render them as crisp PNG images.
- Keep fenced code blocks as native X code blocks and standalone X status URLs as native post embeds.
- Render Mermaid diagrams to 2x PNG images in your browser (no manual screenshots).
- Upload and set a cover image from frontmatter (cover:) or the Images panel.
- Convert footnotes to endnotes and flatten simple nested lists in one click, with line-level diagnostics for anything X cannot represent.
- Works with the open-source md2xarticle agent skill (md2xarticle.com/x-article-agent-skill) when you enable the optional "Create drafts without this review" setting.

How to use:
1. Install the extension and open https://md2xarticle.com/.
2. Paste or import a Markdown file (or load the built-in example) and attach your image folder if needed.
3. Click Create X draft, then confirm in the extension's review page (or enable "Create drafts without this review" to skip the extra click on future drafts).
4. Review and publish the resulting draft in X.

Privacy and boundaries:
Markdown and images are prepared locally in your browser without an md2xarticle account. The extension sends your title, body, images, and cover directly to X only after your confirmation in the review page—or straight from Create X draft if you opted into skipping the review. It uses your existing X tab session, never asks for your password, and contains no ads or analytics tracking. Website visit statistics are documented separately at https://md2xarticle.com/privacy.

Creating drafts requires an X account with Articles access; publishing always happens in X. This tool uses X's web editor interfaces, which X may change. md2xarticle is independent and is not affiliated with or endorsed by X Corp.

## Single purpose

Create an X Article draft, including its prepared images and optional cover, from a Markdown article explicitly handed off by the user at md2xarticle.com. The extension uploads it to the user's existing X Articles session only after the user confirms in the extension's review page, or, if the user turned on the optional Create drafts without this review setting (off by default), after the user chooses Create X draft on the website.

## Permission justifications

scripting: Injects the packaged x-runner.js into a loaded x.com/compose/articles tab after the user confirms Create X draft in the review page, or chooses it on the website when the optional setting that skips the review is on. The extension reuses an existing tab or opens one automatically. The runner uploads the prepared images and optional cover, creates the article draft, and sets its cover using that tab's X session. All executable code is bundled in the extension.

Host permissions: https://md2xarticle.com/* allows the content script to receive a user-initiated article handoff from this exact website. https://x.com/compose/articles* allows the extension to locate the user's X Articles tab and run the bundled draft client there. No content scripts run on unrelated sites. There is no all-sites, tabs, cookies, or upload-host permission.

Remote code: No. All JavaScript is included in the extension. X operation IDs are data read from resource timing or bundled fallback constants; no remote executable code is downloaded or evaluated.

Data disclosures: Website content (article title, body, images and associated file names); authentication information (X anti-forgery token and existing X session used only within the X tab to authenticate the requested operation). No sale, unrelated use, advertising, credit/lending use, or general browsing tracking.

Full workflow for reference:

No Article Studio login or developer-managed service account is required.

1. Install the submitted extension, open https://md2xarticle.com/, and refresh the page if it was already open.
2. Click Example, then Load example. It contains text, a local sample image, a table, and a Mermaid flowchart. Wait for the preview to finish.
3. Click Create X draft in the website. The extension-owned review page opens with the title "A calmer way to publish", the prepared article body, and two image thumbnails. This step performs no X upload.
4. With no X Articles tab open, click Create X draft in the review. The extension opens https://x.com/compose/articles automatically and waits for it to load. If signed out, the X tab is focused and the review asks you to sign in before retrying. Discard staged article deletes the local staged job.
5. To test actual draft creation, use a reviewer-controlled X account with Articles access in the same Chrome profile. X controls account/subscription eligibility; we do not provide or operate X accounts. Repeat steps 2-3 and confirm Create X draft. No pre-opened X tab is required. This uploads the image assets and creates an unpublished X Article. Open the result in X to inspect the text, native table and image order. Publishing is a separate action in X.
6. Clicking the extension toolbar icon opens md2xarticle.com.

The extension uses a packaged @kaitox/x-article client in the X tab's MAIN world. It uses the page's X session, reads ct0 locally, and sends requests directly to X. It does not export credentials to the website or a developer server. X's private editor operation IDs can change, so X integration availability is subject to X's current service.
